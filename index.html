ℹ️ INFORMAÇÕES SOBRE A CONJECTURA DE COLLATZ

📚 O Que É a Conjectura de Collatz?

A Conjectura de Collatz é um dos problemas não resolvidos mais simples de enunciar, porém extremamente intrigante em matemática. Também conhecida como problema 3n+1, ela afirma que a sequência sempre chegará a 1, independentemente do número inteiro positivo com o qual se comece.

⚙️ Como Funciona?

Regra: Dado um número n:
• Se n é PAR: divida por 2
• Se n é ÍMPAR: multiplique por 3 e adicione 1
• Repita até chegar a 1

Exemplo com n=27:
27 → 82 → 41 → 124 → 62 → 31 → 94 → 47 → 142 → 71 → 214 → 107 → 322 → 161 → 484 → 242 → 121 → 364 → 182 → 91 → 274 → 137 → 412 → 206 → 103 → 310 → 155 → 466 → 233 → 700 → 350 → 175 → 526 → 263 → 790 → 395 → 1186 → 593 → 1780 → 890 → 445 → 1336 → 668 → 334 → 167 → 502 → 251 → 754 → 377 → 1132 → 566 → 283 → 850 → 425 → 1276 → 638 → 319 → 958 → 479 → 1438 → 719 → 2158 → 1079 → 3238 → 1619 → 4858 → 2429 → 7288 → 3644 → 1822 → 911 → 2734 → 1367 → 4102 → 2051 → 6154 → 3077 → 9232 → 4616 → 2308 → 1154 → 577 → 1732 → 866 → 433 → 1300 → 650 → 325 → 976 → 488 → 244 → 122 → 61 → 184 → 92 → 46 → 23 → 70 → 35 → 106 → 53 → 160 → 80 → 40 → 20 → 10 → 5 → 16 → 8 → 4 → 2 → 1 (112 passos)

🔬 Fatos Científicos:

• Formulada em 1937 por Lothar Collatz
• Números até 2^68 (≈ 2,95 × 10¹⁹) já foram verificados computacionalmente
• Nenhuma exceção foi encontrada até hoje
• Conjecturado por mathematicians como verdadeiro, mas nunca foi provado
• Computacionalmente verificada para bilhões de números
• Comportamento ainda não é totalmente compreendido

🎓 Curiosidades Matemáticas:

• A sequência pode crescer exponencialmente antes de diminuir
• O maior valor já encontrado em um número pequeno é notavelmente alto
• Não há ciclos conhecidos exceto o trivial (4 → 2 → 1)
• O comprimento da sequência varia de forma aparentemente aleatória
• Números diferentes podem convergir para a mesma sequência
• A densidade de números com sequências longas é muito baixa
